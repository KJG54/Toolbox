# Godot project adapter

Scaffold or inspect a local Godot project without downloading, launching, or configuring the engine:

```powershell
toolbox game godot-scaffold --name "My Prototype" --output outputs/my-godot-game
toolbox game godot-inspect outputs/my-godot-game
toolbox game godot-import-map outputs/my-godot-game
```

Open the result in a locally installed Godot editor to import and test it.
