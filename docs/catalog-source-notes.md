# Catalog source notes

Reviewed 2026-08-18. These records identify source-level conditions; individual assets still need
their own provenance and license check before acquisition.

- [Poly Haven license](https://polyhaven.com/license): assets are CC0 and may be used commercially.
- [Kenney support](https://www.kenney.nl/support): game assets on asset pages are CC0; attribution is optional.
- [Freesound license FAQ](https://freesound.org/help/faq/): each sound's selected license controls commercial use and attribution.
- [Microsoft Florence-2 Base model card](https://huggingface.co/microsoft/Florence-2-base): approved and locally cached semantic-vision runtime; MIT license, revision `5ca5edf5bd017b9919c05d08aebef5e4c7ac3bac`.
- [Pillow license](https://github.com/python-pillow/Pillow/blob/main/LICENSE): image preparation dependency under the MIT-CMU license.
- [ACE-Step project](https://github.com/ace-step/ACE-Step): approved local-only music component; Turbo runtime and model weights are installed for the current RTX 2060 profile and remain subject to output-license review.

For the exact local-runtime code and the installation decision, see
